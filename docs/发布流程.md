# 发布流程（GitHub）

面向第一次发 GitHub 的人。两条路线，任选一条；**别把 `FEFW Save Editor 中文版.exe` 塞进仓库**——
它 26 MB，网页上传单文件上限 25 MB，而且仓库放二进制也不合适。exe 走 **Release 附件**。

| 要上传的东西 | 去哪 | 大小 |
|---|---|---|
| `github/` 目录里的源码、数据、文档 | 仓库（Repository） | 最大单文件 4.2 MB（`flag_names.json`） |
| `release/FEFW-Save-Editor-zh-cn-v1.3.6-win64.zip` | 发布页（Releases）作为附件 | 29.8 MB |

---

## 路线 A：浏览器上传，不装任何工具

1. 打开 <https://github.com/new>
   - Repository name：`fefw-editor-zh-cn`
   - 选 **Public**
   - 下面的 “Add a README / .gitignore / license” **全部不勾**
   - Create repository
2. 新仓库页面点 **uploading an existing file**（或 “Add file → Upload files”）
3. 打开本机的 `…\fefw-editor-main\fefw-editor-main\github` 文件夹，
   **全选里面的内容**（Ctrl+A，是里面的文件，不是外层文件夹），拖进网页
   - 网页支持直接拖文件夹（`docs`、`icons` 会整目录带上去）
4. 下方 Commit changes，写在描述里比如 `Chinese localization + memory mode, v1.3.6`
5. 建发布：仓库页右侧 **Releases → Draft a new release**
   - Tag：`v1.3.6`（新建 tag）
   - Title：`v1.3.6 中文版（含内存模式）`
   - 描述里写三五行更新点即可
   - 把 `release/FEFW-Save-Editor-zh-cn-v1.3.6-win64.zip` 拖进 “Attach binaries”
   - **Publish release**

## 路线 B：装 Git，命令行推（以后更新方便）

1. 装 Git for Windows：<https://git-scm.com/download/win>（一路下一步即可）
   装完重开一个终端，`git --version` 能出版本号。
2. 在 GitHub 上先建好空仓库（同路线 A 第 1 步）。
3. 推上去：

```powershell
cd "D:\fefw-recomp-0.1.6\fefw-editor-main\fefw-editor-main\github"

git init
git add .
git commit -m "Chinese localization + memory mode (v1.3.6)"
git branch -M main
git remote add origin https://github.com/<你的用户名>/fefw-editor-zh-cn.git
git push -u origin main
```

第一次 `push` 会弹一个浏览器窗口让你登录 GitHub（Git Credential Manager），
点授权就行——**不需要把密码抄给任何人**。之后改文件只要 `git add .` /
`git commit` / `git push` 三步。

打 tag（可选，让 Release 和源码对得上）：

```powershell
git tag v1.3.6
git push origin v1.3.6
```

## 关于“把账号交给助手”

不用。助手的定位是**把仓库准备到"一条命令就能推"的状态**，登录这一步始终由你本人在
浏览器里点授权完成——这样密码和二次验证码不会经过任何第三方。真要让助手代跑
`git push`，也只需要你先把 Git 装好并自己完成一次浏览器登录，之后助手在本地执行推送命令即可。

如果确实想用 Personal Access Token（PAT）让命令行免登录，注意：

* 只在 **Settings → Developer settings → Personal access tokens → Fine-grained** 里建，
  权限只勾 `Contents: Read and write` 和这一个仓库；
* 用完立刻在 GitHub 上 **Revoke**；
* 不要把 token 写进任何会提交的文件（本仓库 `.gitignore` 已忽略 `*.tmp`、`settings` 类文件）。

## 之后的版本更新

1. 改代码 → 更新 `editor.py` 里的 `__version__`
2. 重新打包（命令见 `打包说明.md`）
3. `git add . && git commit -m "..." && git push`
4. 新 Release：tag `v1.3.7`，附件换成新的 zip

`release/`、`release-zh-cn/`、`build_out/`、`build_tmp/`、`logs/` 都已在 `.gitignore` 里，
不会被误提交。
